## 1. 命令系统重构

### 1.1 现状问题

当前斜杠命令完全硬编码在 `index.ts` 的 `runRepl()` 中：

```typescript
// 当前实现（硬编码）
if (trimmed === '/help') { ... }
else if (trimmed === '/compact') { ... }
else if (trimmed === '/sessions') { ... }
// ... 每个命令一个 if 分支
```

**问题**：
- 扩展性差：每新增命令需修改 REPL 主循环
- 无法 Tab 补全：命令列表分散在 if/else 中
- 无法动态注册：Skill 无法作为命令使用

### 1.2 新设计：命令注册表

参考 PaiCLI 的 `CliCommandParser`，实现统一的命令注册机制。

```typescript
// src/commands/registry.ts

/** 命令定义 */
export interface CommandDefinition {
  name: string                    // 命令名（不含 /）
  aliases?: string[]              // 别名（如 /? -> /help）
  description: string             // 帮助描述
  args?: {                        // 参数定义
    name: string
    required: boolean
    description: string
  }[]
  handler: CommandHandler         // 处理函数
}

/** 命令处理函数 */
export type CommandHandler = (
  args: string,                   // 原始参数字符串
  ctx: CommandContext              // 执行上下文
) => Promise<void | string>       // 返回值作为输出显示

/** 命令执行上下文 */
export interface CommandContext {
  agent: SparkAgent               // Agent 实例
  config: SparkConfig             // 配置
  cwd: string                     // 工作目录
  print: (text: string) => void   // 输出函数
}

/** 命令注册表 */
export class CommandRegistry {
  private commands = new Map<string, CommandDefinition>()
  private aliases = new Map<string, string>()  // alias -> canonical name

  /** 注册命令 */
  register(def: CommandDefinition): () => void {
    this.commands.set(def.name, def)
    // 注册别名
    for (const alias of def.aliases ?? []) {
      this.aliases.set(alias, def.name)
    }
    return () => {
      this.commands.delete(def.name)
      for (const alias of def.aliases ?? []) {
        this.aliases.delete(alias)
      }
    }
  }

  /** 解析并执行命令 */
  async execute(input: string, ctx: CommandContext): Promise<boolean> {
    if (!input.startsWith('/')) return false

    const [namePart, ...rest] = input.slice(1).split(/\s+/)
    const name = namePart.toLowerCase()
    const args = rest.join(' ')

    // 查找命令（支持别名）
    const canonical = this.aliases.get(name) ?? name
    const cmd = this.commands.get(canonical)
    if (!cmd) return false

    const result = await cmd.handler(args, ctx)
    if (result) ctx.print(result)
    return true
  }

  /** 获取所有命令名（用于 Tab 补全） */
  getAllNames(): string[] {
    const names = new Set<string>()
    for (const name of this.commands.keys()) names.add(name)
    for (const alias of this.aliases.keys()) names.add(alias)
    return [...names]
  }

  /** 获取命令定义 */
  get(name: string): CommandDefinition | undefined {
    const canonical = this.aliases.get(name) ?? name
    return this.commands.get(canonical)
  }

  /** 格式化帮助文本 */
  formatHelp(): string {
    const lines = ['Available commands:']
    for (const [name, cmd] of this.commands) {
      const args = cmd.args?.map(a => a.required ? `<${a.name}>` : `[${a.name}]`).join(' ') ?? ''
      lines.push(`  /${name} ${args}  ${cmd.description}`)
    }
    return lines.join('\n')
  }
}
```

### 1.4 REPL 简化

```typescript
// src/index.ts — 简化后的 REPL 循环

async function runRepl(agent: SparkAgent, registry: CommandRegistry) {
  const rl = readline.createInterface({ input: process.stdin, output: process.stdout })

  while (true) {
    const input = await rl.question('> ')
    const trimmed = input.trim()
    if (!trimmed) continue

    // 1. 尝试执行命令
    const handled = await registry.execute(trimmed, { agent, config, cwd, print: console.log })
    if (handled) continue

    // 2. Shell 命令（! 前缀）
    if (trimmed.startsWith('!')) {
      await executeShell(trimmed.slice(1))
      continue
    }

    // 3. 发送给 Agent
    agent.followup(trimmed)
  }
}
```

### 2.4 /model 命令实现

```typescript
// src/commands/model.ts

export function registerModelCommand(registry: CommandRegistry, presets: ModelPreset[]) {
  registry.register({
    name: 'model',
    aliases: ['m'],
    description: 'Switch LLM model',
    args: [{ name: 'name', required: false, description: 'Model name or index' }],
    handler: async (args, ctx) => {
      // 无参数：显示模型列表
      if (!args) {
        const lines = ['Available models:']
        presets.forEach((p, i) => {
          const current = p.name === ctx.agent.currentModel ? ' (current)' : ''
          lines.push(`  ${i + 1}. ${p.name}${current}`)
        })
        lines.push('')
        lines.push('Usage: /model <name> or /model <number>')
        return lines.join('\n')
      }

      // 按名称查找
      let preset = presets.find(p => p.name === args)

      // 按序号查找
      if (!preset) {
        const index = parseInt(args) - 1
        if (index >= 0 && index < presets.length) {
          preset = presets[index]
        }
      }

      if (!preset) {
        return `Unknown model: ${args}. Use /model to see available models.`
      }

      // 执行切换
      ctx.agent.setModel(preset.model, preset.baseURL)
      return `Switched to model: ${preset.name}`
    },
  })
}
```

## 3. Skill 系统

### 3.1 设计目标

参考 PaiCLI 的 Skill 系统：
- 支持项目级 (`.spark/commands/`) 和用户级 (`~/.spark/commands/`) 两层目录
- Markdown 文件格式，YAML frontmatter 定义元数据
- `$ARGUMENTS` 占位符替换
- Tab 补全支持

### 3.2 Skill 文件格式

```markdown
---
description: Fix a GitHub issue
---
Fix the following GitHub issue:
$ARGUMENTS

Search for relevant files, understand the context, apply the fix, and run tests.
```

- 文件名（去掉 `.md`）即为命令名
- `$ARGUMENTS` 替换为用户输入的参数
- YAML frontmatter 可选，`description` 用于帮助列表

### 3.3 Skill 加载器

```typescript
// src/skills/loader.ts

import * as fs from 'fs/promises'
import * as path from 'path'
import * as os from 'os'

export interface SkillDefinition {
  name: string                    // 命令名（文件名去掉 .md）
  description: string             // 描述（来自 frontmatter）
  body: string                    // 模板内容（frontmatter 之后）
  source: 'user' | 'project'     // 来源
}

/** 解析 YAML frontmatter（极简实现） */
function parseFrontmatter(content: string): { meta: Record<string, string>; body: string } {
  const match = content.match(/^---\n([\s\S]*?)\n---\n([\s\S]*)$/)
  if (!match) return { meta: {}, body: content }

  const meta: Record<string, string> = {}
  for (const line of match[1].split('\n')) {
    const colonIndex = line.indexOf(':')
    if (colonIndex > 0) {
      const key = line.slice(0, colonIndex).trim()
      const value = line.slice(colonIndex + 1).trim()
      meta[key] = value
    }
  }

  return { meta, body: match[2] }
}

/** 加载目录下的所有 Skill */
async function loadSkillsFromDir(dir: string, source: 'user' | 'project'): Promise<SkillDefinition[]> {
  const skills: SkillDefinition[] = []

  try {
    const entries = await fs.readdir(dir, { withFileTypes: true })
    for (const entry of entries) {
      if (!entry.isFile() || !entry.name.endsWith('.md')) continue

      const name = entry.name.replace(/\.md$/, '')
      const content = await fs.readFile(path.join(dir, entry.name), 'utf-8')
      const { meta, body } = parseFrontmatter(content)

      skills.push({
        name,
        description: meta.description ?? 'No description',
        body,
        source,
      })
    }
  } catch {
    // 目录不存在，忽略
  }

  return skills
}

/** 加载所有 Skill（项目级覆盖用户级同名） */
export async function loadAllSkills(cwd: string): Promise<SkillDefinition[]> {
  const userDir = path.join(os.homedir(), '.spark', 'commands')
  const projectDir = path.join(cwd, '.spark', 'commands')

  const userSkills = await loadSkillsFromDir(userDir, 'user')
  const projectSkills = await loadSkillsFromDir(projectDir, 'project')

  // 合并：项目级覆盖用户级同名
  const merged = new Map<string, SkillDefinition>()
  for (const skill of userSkills) merged.set(skill.name, skill)
  for (const skill of projectSkills) merged.set(skill.name, skill)

  return [...merged.values()]
}
```

### 3.4 Skill 命令注册

```typescript
// src/commands/skills.ts

export function registerSkillCommands(
  registry: CommandRegistry,
  skills: SkillDefinition[],
  ctx: CommandContext
) {
  // /skills — 列出所有 Skill
  registry.register({
    name: 'skills',
    description: 'List available skills',
    handler: () => {
      if (skills.length === 0) {
        return 'No skills found. Create .spark/commands/*.md to add skills.'
      }

      const lines = ['Available skills:']
      for (const skill of skills) {
        lines.push(`  /${skill.name}  ${skill.description} (${skill.source})`)
      }
      return lines.join('\n')
    },
  })

  // 注册每个 Skill 为独立命令
  for (const skill of skills) {
    registry.register({
      name: skill.name,
      description: skill.description,
      args: [{ name: 'args', required: false, description: 'Arguments to pass' }],
      handler: async (args) => {
        // 替换 $ARGUMENTS 占位符
        const processed = skill.body.replace(/\$ARGUMENTS/g, args ?? '')

        // 作为用户消息发送给 Agent
        ctx.agent.followup(processed)
        return `Executing skill: ${skill.name}`
      },
    })
  }
}
```

```typescript
// src/commands/effort.ts

export function registerEffortCommand(registry: CommandRegistry, ctx: CommandContext) {
  registry.register({
    name: 'effort',
    description: 'Set reasoning effort level',
    args: [{ name: 'level', required: false, description: 'low/medium/high' }],
    handler: async (args) => {
      const validLevels: EffortLevel[] = ['low', 'medium', 'high']

      if (!args) {
        return `Current effort: ${ctx.agent.effort}\nUsage: /effort <${validLevels.join('|')}>`
      }

      const level = args.toLowerCase() as EffortLevel
      if (!validLevels.includes(level)) {
        return `Invalid effort level: ${args}. Valid: ${validLevels.join(', ')}`
      }

      ctx.agent.setEffort(level)
      return `Effort set to: ${level}`
    },
  })
}
```

```typescript
// src/ui/completer.ts

import { CommandRegistry } from '../commands/registry'

export function createCompleter(registry: CommandRegistry) {
  return function completer(line: string): [string[], string] {
    // 只对 / 开头的输入补全
    if (!line.startsWith('/')) {
      return [[], line]
    }

    const partial = line.slice(1).toLowerCase()
    const allCommands = registry.getAllNames()

    // 前缀匹配
    const matches = allCommands
      .filter(name => name.startsWith(partial))
      .map(name => `/${name}`)

    return [matches, line]
  }
}
```

```typescript
// src/ui/prompt.ts

export function buildPrompt(agent: SparkAgent): string {
  const parts = ['⚡ spark']

  // 模型名
  parts.push(`[${agent.currentModel}]`)

  // 模式（非 normal 时显示）
  if (agent.mode !== 'normal') {
    parts.push(`[${agent.mode}]`)
  }

  // effort（非 medium 时显示）
  if (agent.effort !== 'medium') {
    parts.push(`[${agent.effort}]`)
  }

  return parts.join(' ') + ' > '
}
```

## 10. 参考 PaiCLI 的设计决策

### 10.1 命令系统

**PaiCLI 方案**：47 种命令类型，`CliCommandParser` 统一解析
**SparkCode 方案**：CommandRegistry 注册机制，更灵活的扩展性

### 10.2 Skill 系统

**PaiCLI 方案**：三层覆盖（builtin/user/project），两阶段注入
**SparkCode 方案**：两层覆盖（user/project），直接作为命令执行

简化原因：SparkCode 是个人项目，不需要内置 Skill 和复杂的注入机制

### 10.3 模式切换

**PaiCLI 方案**：ReAct/Plan/Multi-Agent 三种独立 Agent 类
**SparkCode 方案**：单一 Agent + 模式配置 + 工具过滤

简化原因：M6 先实现基础模式，M7 后续可扩展 Plan-and-Execute

### 10.4 模型切换

**PaiCLI 方案**：工厂模式创建不同 Provider 客户端
**SparkCode 方案**：复用 OpenAI 兼容客户端，仅切换 model/baseURL

简化原因：SparkCode 统一使用 OpenAI 兼容协议，不需要多 Provider 支持
