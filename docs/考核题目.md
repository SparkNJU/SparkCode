### **软件工程专业推免项目：构建编程智能体**

#### **【题目】**

个人独立设计并实现一个编程智能体（coding agent）：它通过与大语言模型交互，能自主地读写文件、执行命令，完成你交给它的编程任务 —— 类似一个简化的 Claude Code、Codex、OpenCode、DeepSeek Harness 等。

功能繁简不限，可以很简单，也可以做得完善。不允许在现成 agent 产品上封装界面，也不得使用任何 agent 框架 / SDK（LangChain、LlamaIndex、OpenAI Agents SDK、Claude Agent SDK、AutoGen、CrewAI 等）。允许使用模型厂商的 API 客户端库、OpenAI 兼容网关及模型原生的 tool calling 接口，但不得依赖 API 服务端托管的代码执行或文件工具（如 Code Interpreter、Files API）；重要逻辑需自行编写，包括但不限于：对话历史与上下文管理、工具的定义与本地执行、模型输出的解析、循环终止条件、错误处理。

---

#### **【规则】**

1. **截止时间**：2026 年 9 月 2 日 24:00（北京时间，即 9 月 3 日 0 点）；
2. 允许并鼓励使用任何 AI 工具辅助开发，但你须对项目中的每一处设计负责；
3. agent 运行时调用的模型不限，编程语言不限；
4. API key 等凭据一律通过环境变量或未入库的配置文件提供，不得出现在仓库、README.txt 或视频中；若曾误提交，请立即作废更换。

---

#### **【提交物（共三项）】**

1. **Git 仓库**：须为题目发布后新建的公开仓库（GitHub、Gitee 均可）；保留完整提交历史，不得压缩或改写已推送的历史；截止时间后请勿再向仓库推送新提交。评委会结合提交时间与内容了解你的开发过程。地址写在提交的 README.txt 中。
2. **README.txt（1000 汉字以内）**：Git 仓库地址；如何运行；特色功能说明；其它你想说明的内容。
3. **视频（2 分钟以内）**：演示你的 agent 完成一个真实编程任务的过程，并简要讲解功能实现；允许剪辑与加速播放；mp4 格式、不超过 200 MB。

> 
> **提交方式**：提交内容仅包含一个用你的姓名命名的 zip 文件（将 README.txt 和视频文件压缩成 “你的姓名”.zip）。
> 提交至：`https://table.nju.edu.cn/dtable/forms/283d6c7d-475a-4f41-8baf-d3f45966ef2d/` （可重复提交，以最后一次为准）

---

#### **【面试环节】**

现场播放你的视频，然后你简单介绍你的设计方案，之后回答评委提问，提问重点关注：你是否理解你的 agent 为什么这样运转，是否能为你的设计决策给出辩护。
