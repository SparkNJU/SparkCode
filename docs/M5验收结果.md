## 双状态架构

### 状态一：Picker 模态（会话选择器）

| 按键 | 行为 |
|------|------|
| `↑` | 光标向上移动 |
| `↓` | 光标向下移动 |
| `→` | 加载选中会话（等价 Enter） |
| `←` | 取消，返回原会话（等价 Esc） |
| `Enter` | 加载选中会话 |
| `Esc` / `q` | 取消，返回原会话 |
| `Ctrl-X` | 删除选中会话（Y 确认/n 取消） |

### 状态二：REPL 聊天状态

| 按键 | 行为 |
|------|------|
| `←` / `→` | 移动输入框文本光标（不触发会话切换） |
| `↑` / `↓` | 遍历本地输入历史 |
| `Enter` | 提交输入内容 |
| `Ctrl-C` | 中断当前 Agent 循环 |

## 存储结构

```
~/.spark-code/sessions/
  <sessionId>.jsonl      # 事件日志（append-only）
  <sessionId>.meta.json  # 会话元数据
```

### 元数据格式

```json
{
  "id": "m8x9k2_a1",
  "createdAt": 1735500000000,
  "lastActiveAt": 1735500300000,
  "messageCount": 15,
  "title": "修复登录 bug"
}
```
