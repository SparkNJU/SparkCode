## 4. 文件详解

### Step 1: `src/tools/guard.ts` — 写守卫（新建）

**职责**：校验文件路径是否在工作区内，防止越界写入。

```typescript
// tools/guard.ts — 写守卫

import { resolve, relative, isAbsolute } from 'node:path'
import { access, constants } from 'node:fs/promises'

/**
 * 解析路径为绝对路径（相对于 cwd）
 */
export function resolvePath(cwd: string, filePath: string): string {
  if (isAbsolute(filePath)) return resolve(filePath)
  return resolve(cwd, filePath)
}

/**
 * 检查路径是否在工作区内
 */
export function isWithinWorkspace(absPath: string, cwd: string): boolean {
  const rel = relative(cwd, absPath)
  return !rel.startsWith('..') && !isAbsolute(rel)
}

/**
 * 写守卫：校验路径可写
 * - 必须是绝对路径
 * - 必须在 cwd 内（workspaceOnly 模式）
 * - 父目录必须存在
 */
export async function assertWritable(absPath: string, cwd: string): Promise<void> {
  if (!isWithinWorkspace(absPath, cwd)) {
    throw new Error(`写入被拒绝：路径 "${absPath}" 不在工作区 "${cwd}" 内`)
  }

  // 检查父目录是否存在
  const parent = resolve(absPath, '..')
  try {
    await access(parent, constants.W_OK)
  } catch {
    throw new Error(`写入被拒绝：父目录 "${parent}" 不存在或不可写`)
  }
}

/**
 * 读守卫：校验路径可读
 */
export async function assertReadable(absPath: string, cwd: string): Promise<void> {
  if (!isWithinWorkspace(absPath, cwd)) {
    throw new Error(`读取被拒绝：路径 "${absPath}" 不在工作区 "${cwd}" 内`)
  }

  try {
    await access(absPath, constants.R_OK)
  } catch {
    throw new Error(`读取失败：文件 "${absPath}" 不存在或不可读`)
  }
}
```

**设计要点**：
1. **resolvePath**：相对路径基于 cwd 解析为绝对路径
2. **isWithinWorkspace**：用 `relative()` 检查路径是否逃逸（`..` 或绝对路径）
3. **assertWritable**：写前校验——工作区内 + 父目录存在
4. **assertReadable**：读前校验——工作区内 + 文件可读

### Step 2: `src/tools/fs.ts` — 文件读写编辑（新建）

**职责**：实现 `read`、`write`、`edit` 三个工具。

#### 4.1 `read` 工具

```typescript
// tools/fs.ts — read 工具

import { readFile, writeFile, mkdir } from 'node:fs/promises'
import { dirname } from 'node:path'
import type { ToolDefinition, ToolResult, ToolRunContext } from './types.js'
import { resolvePath, assertReadable, assertWritable } from './guard.js'

export const readTool: ToolDefinition = {
  schema: {
    type: 'function',
    function: {
      name: 'read',
      description: '读取文件内容。返回带行号的内容。offset/limit 控制读取范围（行为单位，从 0 计）。',
      parameters: {
        type: 'object',
        properties: {
          path: { type: 'string', description: '文件路径（相对或绝对）' },
          offset: { type: 'integer', description: '起始行（从 0 计），默认 0' },
          limit: { type: 'integer', description: '读取行数，默认读取全部' },
        },
        required: ['path'],
        additionalProperties: false,
      },
    },
  },

  async execute(args, ctx): Promise<ToolResult> {
    const { path, offset = 0, limit } = args as {
      path: string; offset?: number; limit?: number
    }

    const abs = resolvePath(ctx.cwd, path)
    await assertReadable(abs, ctx.cwd)

    const text = await readFile(abs, 'utf8')
    const content = renderRead(abs, text, offset, limit)

    return {
      content: truncate(content, 50_000),
      isError: false,
      meta: { path: abs, totalLines: text.split('\n').length },
    }
  },
}

/** 渲染带行号的文件内容 */
function renderRead(absPath: string, text: string, offset: number, limit?: number): string {
  const allLines = text.split('\n')
  const start = Math.max(0, offset)
  const end = limit != null ? Math.min(allLines.length, start + limit) : allLines.length
  const lines = allLines.slice(start, end)

  const lineNumberWidth = String(end - 1).length
  const numbered = lines.map((line, i) => {
    const num = String(start + i).padStart(lineNumberWidth, ' ')
    return `${num}\t${line}`
  })

  const header = `--- ${absPath} (行 ${start + 1}-${end}，共 ${allLines.length} 行) ---`
  return [header, ...numbered].join('\n')
}
```

#### 4.3 `edit` 工具

```typescript
// tools/fs.ts — edit 工具

export const editTool: ToolDefinition = {
  schema: {
    type: 'function',
    function: {
      name: 'edit',
      description: '对文件做精确字符串替换。用 new_string 替换 old_string 的第一次出现。old_string 必须在文件中存在且唯一（除非设置 replace_all）。',
      parameters: {
        type: 'object',
        properties: {
          path: { type: 'string', description: '文件路径' },
          old_string: { type: 'string', description: '要替换的原始字符串' },
          new_string: { type: 'string', description: '替换后的字符串' },
          replace_all: { type: 'boolean', description: '是否替换所有出现，默认 false', default: false },
        },
        required: ['path', 'old_string', 'new_string'],
        additionalProperties: false,
      },
    },
  },

  async execute(args, ctx): Promise<ToolResult> {
    const { path, old_string, new_string, replace_all = false } = args as {
      path: string; old_string: string; new_string: string; replace_all?: boolean
    }

    if (old_string === new_string) {
      return { content: 'Error: old_string 和 new_string 相同，无需替换', isError: true }
    }

    const abs = resolvePath(ctx.cwd, path)
    await assertWritable(abs, ctx.cwd)

    const text = await readFile(abs, 'utf8')

    // 校验 old_string 出现次数
    const count = countOccurrences(text, old_string)
    if (count === 0) {
      return {
        content: `Error: old_string 在文件中未找到。请检查字符串是否精确匹配（包括空格和换行）`,
        isError: true,
      }
    }
    if (count > 1 && !replace_all) {
      return {
        content: `Error: old_string 在文件中出现 ${count} 次。请提供更多上下文使其唯一，或设置 replace_all: true`,
        isError: true,
      }
    }

    // 执行替换
    const newText = replace_all
      ? text.replaceAll(old_string, new_string)
      : text.replace(old_string, new_string)

    await writeFile(abs, newText, 'utf8')

    // 计算 diff 预览
    const diff = computeSimpleDiff(old_string, new_string)

    return {
      content: `文件已编辑：${abs}\n${diff}`,
      isError: false,
      meta: { path: abs, replacements: replace_all ? count : 1 },
    }
  },
}

function countOccurrences(text: string, search: string): number {
  let count = 0
  let pos = 0
  while ((pos = text.indexOf(search, pos)) !== -1) {
    count++
    pos += search.length
  }
  return count
}

function computeSimpleDiff(oldStr: string, newStr: string): string {
  const oldLines = oldStr.split('\n')
  const newLines = newStr.split('\n')
  const parts: string[] = []

  for (const line of oldLines) {
    parts.push(`- ${line}`)
  }
  for (const line of newLines) {
    parts.push(`+ ${line}`)
  }

  return parts.join('\n')
}
```

**设计要点**：
1. **read**：带行号渲染（`cat -n` 风格），支持 offset/limit 分页，结果截断 50,000 字符
2. **write**：自动创建父目录（`mkdir -p` 语义），覆盖写入
3. **edit**：精确字符串替换（Claude Code 风格），校验出现次数，返回 diff 预览
4. **写守卫**：所有写操作前调用 `assertWritable`，拒绝工作区外路径
5. **截断**：read 结果超过 50,000 字符时截断（头 80% + 尾 20%）

### Step 3: `src/tools/search.ts` — 搜索工具（新建）

**职责**：实现 `glob` 和 `grep` 两个搜索工具。

#### 4.4 `glob` 工具

```typescript
// tools/search.ts — glob/grep 工具

import { readdir, stat, readFile } from 'node:fs/promises'
import { join, relative, resolve } from 'node:path'
import type { ToolDefinition, ToolResult, ToolRunContext } from './types.js'
import { resolvePath, isWithinWorkspace } from './guard.js'

export const globTool: ToolDefinition = {
  schema: {
    type: 'function',
    function: {
      name: 'glob',
      description: '按 glob 模式查找文件路径。返回匹配的文件路径列表（相对于工作区）。支持 ** 和 * 通配符。',
      parameters: {
        type: 'object',
        properties: {
          pattern: { type: 'string', description: 'glob 模式，如 "**/*.ts" 或 "src/**/*.test.js"' },
          path: { type: 'string', description: '搜索根目录（默认工作区根目录）' },
        },
        required: ['pattern'],
        additionalProperties: false,
      },
    },
  },

  async execute(args, ctx): Promise<ToolResult> {
    const { pattern, path } = args as { pattern: string; path?: string }

    const root = path ? resolvePath(ctx.cwd, path) : ctx.cwd

    if (!isWithinWorkspace(root, ctx.cwd)) {
      return { content: `Error: 搜索路径 "${root}" 不在工作区内`, isError: true }
    }

    const matches = await globSearch(root, pattern)

    if (matches.length === 0) {
      return { content: `未找到匹配 "${pattern}" 的文件`, isError: false }
    }

    const relPaths = matches.map(m => relative(ctx.cwd, m))
    const content = `找到 ${relPaths.length} 个文件：\n${relPaths.join('\n')}`

    return {
      content: truncate(content, 20_000),
      isError: false,
      meta: { count: relPaths.length, pattern },
    }
  },
}

/** 自研 glob 搜索（支持 ** 和 * 通配符） */
async function globSearch(root: string, pattern: string): Promise<string[]> {
  const parts = pattern.replace(/\\/g, '/').split('/')
  const results: string[] = []
  await walkGlob(root, root, parts, 0, results)
  return results.sort()
}

async function walkGlob(
  base: string,
  current: string,
  parts: string[],
  index: number,
  results: string[],
): Promise<void> {
  if (index >= parts.length) {
    results.push(current)
    return
  }

  const part = parts[index]

  if (part === '**') {
    // ** 匹配零个或多个目录
    // 先尝试跳过（匹配零个）
    await walkGlob(base, current, parts, index + 1, results)
    // 再尝试匹配一个目录
    try {
      const entries = await readdir(current, { withFileTypes: true })
      for (const entry of entries) {
        if (entry.isDirectory() && !entry.name.startsWith('.')) {
          await walkGlob(base, join(current, entry.name), parts, index, results)
        }
      }
    } catch { /* 权限不足等，跳过 */ }
    return
  }

  // 普通 glob 部分：将 * 转为正则
  const regex = new RegExp(
    '^' + part.replace(/\./g, '\\.').replace(/\*/g, '[^/]*').replace(/\?/g, '[^/]') + '$',
  )

  try {
    const entries = await readdir(current, { withFileTypes: true })
    for (const entry of entries) {
      if (regex.test(entry.name)) {
        const fullPath = join(current, entry.name)
        if (index === parts.length - 1) {
          // 最后一个部分：只匹配文件
          const s = await stat(fullPath)
          if (s.isFile()) results.push(fullPath)
        } else if (entry.isDirectory()) {
          await walkGlob(base, fullPath, parts, index + 1, results)
        }
      }
    }
  } catch { /* 权限不足等，跳过 */ }
}
```

#### 4.5 `grep` 工具

```typescript
// tools/search.ts — grep 工具

export const grepTool: ToolDefinition = {
  schema: {
    type: 'function',
    function: {
      name: 'grep',
      description: '在文件中按正则搜索，返回匹配行与行号。默认搜索工作区内所有文件。',
      parameters: {
        type: 'object',
        properties: {
          pattern: { type: 'string', description: '正则表达式（JavaScript RegExp 语法）' },
          path: { type: 'string', description: '搜索路径（文件或目录，默认工作区根目录）' },
          glob: { type: 'string', description: '文件名过滤 glob（如 "*.ts"）' },
        },
        required: ['pattern'],
        additionalProperties: false,
      },
    },
  },

  async execute(args, ctx): Promise<ToolResult> {
    const { pattern, path, glob } = args as {
      pattern: string; path?: string; glob?: string
    }

    const root = path ? resolvePath(ctx.cwd, path) : ctx.cwd

    if (!isWithinWorkspace(root, ctx.cwd)) {
      return { content: `Error: 搜索路径 "${root}" 不在工作区内`, isError: true }
    }

    let regex: RegExp
    try {
      regex = new RegExp(pattern, 'g')
    } catch (e) {
      return { content: `Error: 无效的正则表达式: ${e}`, isError: true }
    }

    // 收集要搜索的文件
    const files = await collectFiles(root, glob)

    // 搜索每个文件
    const matches: Array<{ file: string; line: number; text: string }> = []

    for (const file of files) {
      try {
        const text = await readFile(file, 'utf8')
        const lines = text.split('\n')
        for (let i = 0; i < lines.length; i++) {
          if (regex.test(lines[i])) {
            matches.push({
              file: relative(ctx.cwd, file),
              line: i + 1,
              text: lines[i].trimEnd(),
            })
          }
          regex.lastIndex = 0 // 重置正则状态
        }
      } catch { /* 跳过不可读文件 */ }
    }

    if (matches.length === 0) {
      return { content: `未找到匹配 "${pattern}" 的内容`, isError: false }
    }

    // 渲染结果
    const lines = matches.slice(0, 200).map(m => `${m.file}:${m.line}: ${m.text}`)
    const header = `找到 ${matches.length} 个匹配${matches.length > 200 ? '（显示前 200 个）' : ''}：`
    const content = [header, ...lines].join('\n')

    return {
      content: truncate(content, 30_000),
      isError: false,
      meta: { totalMatches: matches.length, filesSearched: files.length },
    }
  },
}

/** 收集目录下所有文件（跳过 node_modules、.git 等） */
async function collectFiles(root: string, globFilter?: string): Promise<string[]> {
  const SKIP_DIRS = new Set(['node_modules', '.git', 'dist', '.next', '__pycache__'])
  const files: string[] = []

  async function walk(dir: string) {
    try {
      const entries = await readdir(dir, { withFileTypes: true })
      for (const entry of entries) {
        if (entry.name.startsWith('.') && entry.isFile()) continue
        if (SKIP_DIRS.has(entry.name)) continue

        const fullPath = join(dir, entry.name)
        if (entry.isDirectory()) {
          await walk(fullPath)
        } else if (entry.isFile()) {
          // glob 过滤
          if (globFilter && !matchGlob(entry.name, globFilter)) continue
          files.push(fullPath)
        }
      }
    } catch { /* 权限不足，跳过 */ }
  }

  const rootStat = await stat(root)
  if (rootStat.isFile()) {
    files.push(root)
  } else {
    await walk(root)
  }

  return files
}

/** 简单 glob 匹配（仅支持 * 和 ?） */
function matchGlob(name: string, pattern: string): boolean {
  const regex = new RegExp(
    '^' + pattern.replace(/\./g, '\\.').replace(/\*/g, '.*').replace(/\?/g, '.') + '$',
  )
  return regex.test(name)
}
```

**设计要点**：
1. **glob**：自研递归目录遍历，支持 `**`（多层目录）和 `*`（单层文件名）通配符
2. **grep**：自研正则搜索，返回 `file:line: text` 格式，跳过 `node_modules`/`.git` 等目录
3. **结果截断**：glob 截断 20,000 字符，grep 最多显示 200 个匹配 + 截断 30,000 字符
4. **工作区限制**：搜索路径必须在工作区内
5. **错误容错**：权限不足的文件/目录静默跳过

## 6. 数据流（M3 完整版）

```
用户输入 "读取 src/index.ts 并修改欢迎消息"
  ↓
runTurn():
  ↓
  LLM 决定调用 read 工具 → { path: "src/index.ts" }
  ↓
  executeToolCalls():
    readTool.execute({ path: "src/index.ts" })
      → resolvePath(cwd, "src/index.ts") → 绝对路径
      → assertReadable(abs, cwd) → 工作区校验通过
      → readFile(abs, 'utf8') → 文件内容
      → renderRead(abs, text, 0, undefined) → 带行号渲染
      → truncate(content, 50_000) → 截断（如果需要）
    → tool/result 事件 → LLM 看到文件内容
  ↓
  LLM 决定调用 edit 工具 → { path: "src/index.ts", old_string: "旧欢迎消息", new_string: "新欢迎消息" }
  ↓
  executeToolCalls():
    editTool.execute({ path, old_string, new_string })
      → resolvePath → assertWritable → 读文件
      → countOccurrences → 校验唯一性
      → text.replace(old, new) → 写回
      → computeSimpleDiff → diff 预览
    → tool/result 事件 → LLM 看到编辑结果
  ↓
  LLM 生成最终回复："已修改 src/index.ts 的欢迎消息"
  ↓
  turn/end
```

## 8. 关键设计决策（答辩准备）

### Q: 为什么用自研 glob/grep 而不依赖第三方库？

**A**：(1) 技术方案要求"核心逻辑自研"，glob/grep 逻辑清晰可控；(2) 自研可精确控制跳过目录（node_modules、.git）和截断策略；(3) 减少外部依赖，降低打包体积和安全风险。但如果评估后发现自研 glob 复杂度过高，允许使用 `fast-glob`（技术方案 §4.2(3) 注明"通用库，允许"）。

### Q: edit 工具为什么要求 old_string 唯一？

**A**：精确字符串替换的核心价值在于**确定性**——用户（或模型）明确知道修改了哪一处。如果 old_string 出现多次且不报错，可能导致修改了错误位置。强制唯一性是安全机制，replace_all 是显式覆盖。

### Q: 写守卫为什么只检查工作区，不做更严格的沙箱？

**A**：M3 实现 L1 级别（工作区限制）——这是最基础且无争议的安全措施。更高级的沙箱（命令审批、Docker 容器）是 M6 的内容。分层实现符合渐进式开发原则。

### Q: 结果截断策略为什么是 50,000 字符？

**A**：50,000 字符约 12,500 token（英文 4 字符/token），约占 128K 上下文窗口的 10%。保留头 80% + 尾 20%，头部包含文件开头（import、类定义），尾部包含文件结尾（export、结论）。截断后 LLM 可通过 offset/limit 分页读取中间部分。
