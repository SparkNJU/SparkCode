
## 0:40 - 1:30 Agent 自主修复（核心演示）

**画面**：Agent 自主执行，工具调用显示为折叠块。建议保留以下关键步骤（可加速中间过程）：

**第一步：阅读代码**
- `⏵ 📖 read calculator.ts` — Agent 读取计算器源码
- `⏵ 📖 read calculator.test.ts` — Agent 读取测试文件

**第二步：运行测试确认问题**
- `⏵ ⚡ bash npx vitest run` — 运行测试，看到 13 个失败

**第三步：分析并修复**

Agent 识别出 3 个 bug，逐一修复：

1. `⏵ ✏️ edit calculator.ts` — **修复运算符优先级**：`parseExpression` 中调用 `parseFactor` 改为 `parseTerm`
   > 显示 diff

2. `⏵ ✏️ edit calculator.ts` — **修复括号处理**：添加括号不匹配检查，正确跳过 `)`
   > 显示 diff

3. `⏵ ✏️ edit calculator.ts` — **修复除以零**：在 `parseTerm` 中添加零除检查
   > 显示 diff

**第四步：验证**
- `⏵ ⚡ bash npx vitest run` — 运行测试

**画面**：测试结果
```
✓ 25 tests passed
```

**旁白**：
> "Agent 自主阅读了源码和测试，定位到三个 bug — 运算符优先级错误、括号解析缺陷、除以零未处理 — 逐一修复后所有测试通过。"

## 录制注意事项

1. **终端设置**：深色背景，字号 ≥ 16pt，确保手机观看清晰
2. **分辨率**：1920×1080 或 1280×720
3. **加速**：Agent 思考等待、重复测试、npm install 等可 2-4 倍速
4. **剪辑**：步骤之间可跳转，但 Agent 的读代码→分析→修复决策过程尽量保留
5. **API Key**：确保环境变量不泄露，必要时遮盖终端标题栏
6. **网络**：确保录制时 API 调用流畅，提前测试连接
7. **Prompt 措辞**：任务描述不要太具体（不要说"修复 parseExpression"），让 agent 自己分析
