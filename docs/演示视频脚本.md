# Spark Code 演示视频脚本（2 分钟）

> 格式：mp4，≤ 200 MB
> 允许剪辑与加速播放

---

## 0:00 - 0:10 开场

**画面**：终端空白，输入命令启动 Spark Code

```bash
npm run spark
```

**画面**：SPARK ASCII art 欢迎横幅 + 状态栏（模型、模式、工作目录）

**旁白**（可选）：
> "这是 Spark Code，一个从零实现的编程智能体，不依赖任何 agent 框架。"

---

## 0:10 - 0:25 提出任务

**画面**：在提示符输入一个真实编程任务

```
> 创建一个 Express 服务器，包含 /health 接口返回 { status: "ok" }，
  然后写一个测试验证它
```

**画面**：显示 Braille spinner（思考动画）+ 推理预览

---

## 0:25 - 1:10 Agent 自主执行（核心演示）

**画面**：Agent 自动执行以下步骤，每步显示工具调用折叠块：

1. **`write`** — 创建 `server.ts`，显示文件内容
2. **`write`** — 创建 `server.test.ts`，测试文件
3. **`bash`** — `npm install express`（可加速）
4. **`bash`** — `npx vitest run` 运行测试
5. 测试**失败** → Agent 读取错误输出
6. **`edit`** — 修复代码（显示 diff）
7. **`bash`** — 再次运行测试 → **通过** ✓

**关键画面**：
- 工具调用显示为 `⏵ ⚡ bash (ctrl+o to expand)` 折叠块
- 代码块自动折叠，提示 `Ctrl+O to expand`
- 流式输出正常滚动，状态栏始终固定在顶部
- 测试结果绿色 ✓ / 红色 ✗

**旁白**：
> "Agent 自主完成了编码、安装依赖、运行测试、根据失败修复代码的完整流程。"

---

## 1:10 - 1:30 交互特性展示

**画面**：快速展示以下操作（可剪辑）：

1. **Ctrl+O** — 展开一个折叠的代码块，再按收起
2. **`/model`** — 切换模型，状态栏实时更新
3. **`/plan`** — 切换到规划模式（状态栏显示 `📋 规划模式`）
4. **Tab 补全** — 输入 `/mo` 按 Tab 补全为 `/model`

## 录制注意事项

1. **终端设置**：深色背景，字号 ≥ 16pt，确保手机观看清晰
2. **分辨率**：1920×1080 或 1280×720
3. **加速**：`npm install`、重复测试等可 2-4 倍速
4. **剪辑**：步骤之间可剪辑跳转，但 Agent 决策过程尽量保留
5. **API Key**：确保环境变量不泄露，必要时遮盖终端标题栏
6. **网络**：确保录制时 API 调用流畅，提前测试连接
