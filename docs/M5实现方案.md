# M5 实现方案：持久化 — JSONL 落盘 + 恢复/续接

> 对应技术方案第 5.2 节"持久化策略"，目标：重启后 `spark --resume` 接续会话。

---

## 1. 目标

| 项 | 说明 |
|---|---|
| **核心功能** | 会话事件实时落盘（JSONL），支持恢复/续接 |
| **验收标准** | 重启后 `spark --resume` 接续会话，对话历史完整 |
| **依赖** | M1（事件日志）、M4（压缩事件） |

---

## 2. 双状态架构

系统有两种互斥的终端状态：

| 状态 | 名称 | 输入来源 | 说明 |
|------|------|----------|------|
| **REPL 聊天状态** | 主界面 | readline 输入框 | 正常聊天，←→ 移动文本光标 |
| **Picker 模态** | 会话选择器 | stdin raw mode | 模态独占，←→ 操作会话 |

**关键约束**：`←`/`→` **仅在 Picker 模态下才是会话操作；回到聊天输入框，左右箭头恢复文本光标的左右移动，不会误触发退出/加载会话**。

---

## 3. 存储设计

### 3.1 存储位置

```
~/.spark-code/sessions/
  <sessionId>.jsonl      # 事件日志（append-only）
  <sessionId>.meta.json  # 会话元数据
```

### 3.2 元数据格式

```typescript
interface SessionMeta {
  id: string              // 会话 ID
  createdAt: number       // 创建时间戳
  lastActiveAt: number    // 最后活跃时间戳
  messageCount: number    // 用户消息条数
  title?: string          // 会话预览标题（截断前 40 字符）
}
```

### 3.3 排序规则

**按 `lastActiveAt` 倒序，最新会话置顶**。

## 5. 分步实现

### Step 1：JSONL 流式写入器

```typescript
// src/persist/writer.ts

import * as fs from 'node:fs'
import * as path from 'node:path'
import type { SessionEvent } from '../core/session.js'

export class JsonlWriter {
  private stream: fs.WriteStream
  private filePath: string

  constructor(dir: string, sessionId: string) {
    fs.mkdirSync(dir, { recursive: true })
    this.filePath = path.join(dir, `${sessionId}.jsonl`)
    this.stream = fs.createWriteStream(this.filePath, { flags: 'a' })
  }

  /** 追加一个事件 */
  write(event: SessionEvent): void {
    this.stream.write(JSON.stringify(event) + '\n')
  }

  /** 关闭流 */
  close(): Promise<void> {
    return new Promise((resolve, reject) => {
      this.stream.end(() => resolve())
      this.stream.once('error', reject)
    })
  }

  get path(): string {
    return this.filePath
  }
}
```

### Step 2：JSONL 读取器

```typescript
// src/persist/reader.ts

import * as fs from 'node:fs'
import type { SessionEvent } from '../core/session.js'

export function readJsonl(filePath: string): SessionEvent[] {
  if (!fs.existsSync(filePath)) return []

  const content = fs.readFileSync(filePath, 'utf-8')
  const lines = content.split('\n').filter(line => line.trim())
  const events: SessionEvent[] = []

  for (const line of lines) {
    try {
      const event = JSON.parse(line) as SessionEvent
      if (event.seq !== undefined && event.type) {
        events.push(event)
      }
    } catch {
      // 跳过损坏的行
    }
  }

  return events
}
```

### Step 3：会话存储管理

```typescript
// src/persist/store.ts

import * as fs from 'node:fs'
import * as path from 'node:path'
import * as os from 'node:os'
import { readJsonl } from './reader.js'

export interface SessionMeta {
  id: string
  createdAt: number
  lastActiveAt: number
  messageCount: number
  title?: string
}

export class SessionStore {
  readonly baseDir: string

  constructor(baseDir?: string) {
    this.baseDir = baseDir ?? path.join(os.homedir(), '.spark-code', 'sessions')
    fs.mkdirSync(this.baseDir, { recursive: true })
  }

  /** 列出所有会话（按 lastActiveAt 倒序） */
  list(): SessionMeta[] {
    const metaFiles = fs.readdirSync(this.baseDir)
      .filter(f => f.endsWith('.meta.json'))

    return metaFiles
      .map(f => {
        try {
          return JSON.parse(fs.readFileSync(path.join(this.baseDir, f), 'utf-8')) as SessionMeta
        } catch {
          return null
        }
      })
      .filter((m): m is SessionMeta => m !== null)
      .sort((a, b) => b.lastActiveAt - a.lastActiveAt)
  }

  /** 保存会话元数据 */
  saveMeta(meta: SessionMeta): void {
    const filePath = path.join(this.baseDir, `${meta.id}.meta.json`)
    fs.writeFileSync(filePath, JSON.stringify(meta, null, 2))
  }

  /** 删除会话（磁盘文件） */
  delete(sessionId: string): void {
    const jsonlPath = path.join(this.baseDir, `${sessionId}.jsonl`)
    const metaPath = path.join(this.baseDir, `${sessionId}.meta.json`)
    if (fs.existsSync(jsonlPath)) fs.unlinkSync(jsonlPath)
    if (fs.existsSync(metaPath)) fs.unlinkSync(metaPath)
  }

  /** 获取最近的会话 ID */
  getLatestId(): string | null {
    const sessions = this.list()
    return sessions.length > 0 ? sessions[0]!.id : null
  }

  /** JSONL 文件路径 */
  jsonlPath(sessionId: string): string {
    return path.join(this.baseDir, `${sessionId}.jsonl`)
  }

  /** 从 JSONL 提取标题（第一条用户消息，截断 40 字符） */
  extractTitle(sessionId: string): string {
    const filePath = this.jsonlPath(sessionId)
    if (!fs.existsSync(filePath)) return ''

    const events = readJsonl(filePath)
    for (const event of events) {
      if (event.type === 'user/message' && event.data?.content) {
        const text = event.data.content as string
        return text.length > 40 ? text.slice(0, 40) + '...' : text
      }
    }
    return ''
  }
}
```

### Step 4：终端会话选择器（模态独占）

```typescript
// src/persist/picker.ts

import type { SessionMeta } from './store.js'

export interface PickerResult {
  action: 'select' | 'cancel' | 'delete'
  sessionId?: string
}

/**
 * 终端会话选择器（模态独占状态）
 *
 * 按键行为：
 * - ↑/↓：移动高亮光标（不越界）
 * - →/Enter：加载选中会话，关闭 Picker
 * - ←/Esc/q：取消，返回原会话
 * - Ctrl-X：删除选中会话（Y 确认/n 取消）
 */
export async function showSessionPicker(
  sessions: SessionMeta[],
  stdout: NodeJS.WriteStream,
  stdin: NodeJS.ReadStream,
): Promise<PickerResult> {
  // 列表为空
  if (sessions.length === 0) {
    stdout.write('\n📭 暂无历史会话\n')
    stdout.write('  按 Enter 创建全新会话 | 按 Esc 取消\n\n')
    return { action: 'cancel' }
  }

  let cursor = 0
  const pageSize = 10
  let scrollOffset = 0

  // 格式化时间
  const formatTime = (ts: number): string => {
    const d = new Date(ts)
    const mm = String(d.getMonth() + 1).padStart(2, '0')
    const dd = String(d.getDate()).padStart(2, '0')
    const hh = String(d.getHours()).padStart(2, '0')
    const mi = String(d.getMinutes()).padStart(2, '0')
    return `${mm}-${dd} ${hh}:${mi}`
  }

  // 渲染函数
  const render = () => {
    stdout.write('\x1B[2J\x1B[H') // 清屏
    stdout.write('\n📂 选择会话:\n\n')

    // 滚动范围
    if (cursor < scrollOffset) scrollOffset = cursor
    if (cursor >= scrollOffset + pageSize) scrollOffset = cursor - pageSize + 1

    const end = Math.min(sessions.length, scrollOffset + pageSize)

    for (let i = scrollOffset; i < end; i++) {
      const s = sessions[i]!
      const isSelected = i === cursor
      const prefix = isSelected ? '❯ ' : '  '
      const idx = String(i + 1).padStart(3, '0')
      const time = formatTime(s.lastActiveAt)
      const msgCount = `${s.messageCount} 条消息`
      const title = s.title ? ` | "${s.title}"` : ''

      stdout.write(`${prefix}[${idx}] ${time} | ${msgCount}${title}\n`)
    }

    if (scrollOffset > 0) stdout.write('  ↑ 更多...\n')
    if (end < sessions.length) stdout.write('  ↓ 更多...\n')

    stdout.write('\n')
    stdout.write('↑↓ 上下移动 | ← → 切换会话 | Enter 加载 | Esc/q 取消 | Ctrl-X 删除\n')
  }

  render()

  return new Promise((resolve) => {
    stdin.setRawMode?.(true)
    stdin.resume()
    stdin.setEncoding('utf-8')

    let deleteConfirm = false

    const onData = (key: string) => {
      // 删除确认状态
      if (deleteConfirm) {
        if (key === 'y' || key === 'Y') {
          const deletedId = sessions[cursor]!.id
          sessions.splice(cursor, 1)
          if (cursor >= sessions.length) cursor = Math.max(0, sessions.length - 1)
          deleteConfirm = false
          render()
          cleanup()
          resolve({ action: 'delete', sessionId: deletedId })
          return
        } else {
          deleteConfirm = false
          render()
          return
        }
      }

      switch (key) {
        case '\x1B[A': // ↑
          cursor = Math.max(0, cursor - 1)
          render()
          break

        case '\x1B[B': // ↓
          cursor = Math.min(sessions.length - 1, cursor + 1)
          render()
          break

        case '\x1B[C': // → 加载选中会话
          cleanup()
          resolve({ action: 'select', sessionId: sessions[cursor]!.id })
          break

        case '\x1B[D': // ← 取消
          cleanup()
          resolve({ action: 'cancel' })
          break

        case '\r': // Enter
          cleanup()
          resolve({ action: 'select', sessionId: sessions[cursor]!.id })
          break

        case '\x1B': // Esc
        case 'q':
          cleanup()
          resolve({ action: 'cancel' })
          break

        case '\x18': // Ctrl-X
          deleteConfirm = true
          stdout.write('\n⚠️  确定要删除该会话? [Y/n] ')
          break
      }
    }

    const cleanup = () => {
      stdin.removeListener('data', onData)
      stdin.setRawMode?.(false)
      stdin.pause()
    }

    stdin.on('data', onData)
  })
}
```

### Step 5：集成到 SparkAgent（修改 `src/core/loop.ts`）

```typescript
import { JsonlWriter } from '../persist/writer.js'
import { SessionStore } from '../persist/store.js'

export class SparkAgent {
  private writer: JsonlWriter | null = null
  private store: SessionStore
  private _persistenceEnabled = false

  constructor(config: SparkConfig) {
    // ... 现有代码 ...
    this.store = new SessionStore()
  }

  /** 启用持久化 */
  enablePersistence(): void {
    this.writer = new JsonlWriter(this.store.baseDir, this.session.id)
    this._persistenceEnabled = true
  }

  /** 停用持久化（删除当前活跃会话磁盘文件后调用） */
  disablePersistence(): void {
    this.writer?.close()
    this.writer = null
    this._persistenceEnabled = false
  }

  /** 修改 appendEvent：同步写入 JSONL */
  private appendEvent<T extends SessionEvent['type']>(
    type: T,
    data: Extract<SessionEvent, { type: T }>['data'],
    options?: { surfaceOp?: 'append' | { op: 'replace'; start: number; end: number } },
  ): Extract<SessionEvent, { type: T }> {
    const event = this.session.append(type, data, options)
    this.writer?.write(event as SessionEvent)
    return event
  }

  /** 恢复会话 */
  async resume(sessionId: string): Promise<void> {
    const filePath = this.store.jsonlPath(sessionId)
    const events = readJsonl(filePath)
    if (events.length === 0) {
      throw new Error(`会话 ${sessionId} 不存在或为空`)
    }
    this.writer?.close()
    this.session.replay(events)
    this.writer = new JsonlWriter(this.store.baseDir, sessionId)
    this._persistenceEnabled = true
    this.saveCurrentMeta()
  }

  /** 新建会话 */
  newSession(): void {
    this.saveCurrentMeta()
    this.writer?.close()
    this.session = new Session()
    this.writer = new JsonlWriter(this.store.baseDir, this.session.id)
    this._persistenceEnabled = true
  }

  /** 保存当前会话元数据 */
  saveCurrentMeta(): void {
    const log = this.session.getLog()
    const userMessages = log.filter(e => e.type === 'user/message')
    const firstUserMsg = userMessages[0]
    const title = firstUserMsg?.data?.content
      ? (firstUserMsg.data.content as string).slice(0, 40)
      : ''

    this.store.saveMeta({
      id: this.session.id,
      createdAt: log.length > 0 ? log[0]!.time : Date.now(),
      lastActiveAt: Date.now(),
      messageCount: userMessages.length,
      title,
    })
  }

  /** 重命名当前会话 */
  renameSession(title: string): void {
    this.store.saveMeta({
      id: this.session.id,
      createdAt: this.session.getLog()[0]?.time ?? Date.now(),
      lastActiveAt: Date.now(),
      messageCount: this.session.getLog().filter(e => e.type === 'user/message').length,
      title,
    })
  }

  /** 删除会话磁盘文件 */
  deleteSession(sessionId: string): void {
    this.store.delete(sessionId)
  }

  get persistenceEnabled(): boolean {
    return this._persistenceEnabled
  }

  getStore(): SessionStore {
    return this.store
  }
}
```

### Step 6：修改 REPL 入口（修改 `src/index.ts`）

```typescript
import { showSessionPicker } from './persist/picker.js'
import { SessionStore } from './persist/store.js'

// ─── CLI 启动参数解析 ───

const args = process.argv.slice(2)
const resumeIdx = args.indexOf('--resume')
let startMode: 'new' | 'picker' | 'latest' | 'specific' = 'new'
let specificId: string | null = null

if (resumeIdx !== -1) {
  const resumeArg = args[resumeIdx + 1]
  if (!resumeArg || resumeArg.startsWith('-')) {
    startMode = 'picker'           // spark --resume → 打开 Picker
  } else if (resumeArg === 'latest') {
    startMode = 'latest'           // spark --resume latest
  } else {
    startMode = 'specific'         // spark --resume <id>
    specificId = resumeArg
  }
}

// ─── 启动流程 ───

const store = new SessionStore()
const agent = new SparkAgent(config)

switch (startMode) {
  case 'new':
    agent.enablePersistence()
    break

  case 'latest': {
    const latestId = store.getLatestId()
    if (latestId) {
      await agent.resume(latestId)
      console.log(`📂 已恢复最近会话: ${latestId}`)
    } else {
      console.log('📭 没有历史会话，创建新会话')
      agent.enablePersistence()
    }
    break
  }

  case 'specific': {
    try {
      await agent.resume(specificId!)
      console.log(`📂 已恢复会话: ${specificId}`)
    } catch {
      console.log(`⚠️  会话 ${specificId} 不存在，打开选择器...`)
      const result = await showSessionPicker(store.list(), stdout, process.stdin)
      if (result.action === 'select' && result.sessionId) {
        await agent.resume(result.sessionId)
      } else {
        agent.enablePersistence()
      }
    }
    break
  }

  case 'picker': {
    const result = await showSessionPicker(store.list(), stdout, process.stdin)
    if (result.action === 'select' && result.sessionId) {
      await agent.resume(result.sessionId)
      console.log(`📂 已恢复会话: ${result.sessionId}`)
    } else {
      agent.enablePersistence() // 取消 → 新建会话
    }
    break
  }
}

// ─── REPL 主循环 ───

while (true) {
  const raw = await rl.question('> ')
  const trimmed = raw.trim()

  // 斜杠元命令
  if (trimmed.startsWith('/')) {
    const [cmd, ...rest] = trimmed.split(/\s+/)

    switch (cmd) {
      case '/resume': {
        const result = await showSessionPicker(store.list(), stdout, process.stdin)
        if (result.action === 'select' && result.sessionId) {
          await agent.resume(result.sessionId)
          stdout.write(`\n📂 已恢复会话: ${result.sessionId}\n\n`)
        } else if (result.action === 'delete' && result.sessionId) {
          agent.deleteSession(result.sessionId)
          stdout.write(`\n🗑️  已删除会话: ${result.sessionId}\n\n`)
        } else {
          stdout.write('\n已取消\n\n')
        }
        continue
      }

      case '/new': {
        agent.newSession()
        stdout.write('\n✨ 已创建新会话\n\n')
        continue
      }

      case '/rename': {
        const title = rest.join(' ').trim()
        if (!title) {
          stdout.write('\n用法: /rename <会话标题>\n\n')
        } else {
          agent.renameSession(title)
          stdout.write(`\n✏️  会话已重命名为: "${title}"\n\n`)
        }
        continue
      }

      case '/compact': { /* 现有逻辑 */ continue }
      case '/help':
      case '/?': {
        stdout.write(`
📖 可用命令:
  /resume         打开会话选择器（↑↓←→ 导航）
  /new            创建新会话

  }
```

## 6. 按键行为表

### Picker 模态

| 按键 | 行为 |
|------|------|
| `↑` | 光标向上移动一条；已是第一条时停留 |
| `↓` | 光标向下移动一条；已是最后一条时停留 |
| `→` | 加载选中会话，关闭 Picker，进入会话（等价 Enter） |
| `←` | 取消，关闭 Picker，返回原会话（等价 Esc） |
| `Enter` | 加载选中会话，关闭 Picker，进入会话 |
| `Esc` / `q` | 取消，关闭 Picker，返回原会话 |
| `Ctrl-X` | 删除选中会话（Y 确认/n 取消） |

### REPL 聊天状态

| 按键 | 行为 |
|------|------|
| `←` / `→` | 移动输入框文本光标（**不触发会话切换**） |
| `↑` / `↓` | 遍历本地输入历史 |
| `Enter` | 提交输入内容 |
| `Ctrl-C` | 中断当前 Agent 循环 |

## 7. 状态流转图

```
程序启动
   ├─ 无参数 → 新建空白会话 →【REPL聊天状态】
   ├─ --resume → 直接进入【Picker模态】
   ├─ --resume latest → 直接加载最近会话 →【REPL聊天状态】
   └─ --resume <id> → 成功加载→REPL；失败→进入Picker模态

【REPL聊天状态】
    │
    │输入 /resume
    ▼
【Picker模态】
    ├─ ↑ ↓：移动高亮光标
    ├─ Enter / → ：加载选中会话 → 回到【REPL聊天状态】（切换会话）
    ├─ Esc / q / ← ：取消，返回打开Picker前的REPL会话（不切换）
    └─ Ctrl-X：删除选中会话（Y确认/n取消），停留在Picker模态继续浏览

⚠️ 离开Picker模态后，← →恢复为输入框文本光标移动，不再操作会话。
```
